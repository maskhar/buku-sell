## Interactive states and implementation traps

- `CHECKOUT` has nine keys: `single`, `four`, `six`, `balik`, `wmethod`, `doseen`, `miring`, `city`, `monetized`; **all values are empty strings**. Delegated document click resolves closest `[data-buy]`; nonempty URL navigates via `window.location.href`; empty URL triggers native alert `Link pembayaran belum dipasang. Isi CHECKOUT di kode halaman.` No checkout form, cart, modal, choice-of-four selector, customer data capture, payment integration, delivery, or DWC.AI provisioning exists. The five buying steps are marketing copy, not implemented functionality. `Pilih Buku` goes to `single` (not a chooser); 4-book package has no selection flow. Closing CTA uses `<a data-buy>` without `href`, so it works via JS click but lacks native link semantics/keyboard activation.
- `TESTIMONIALS=[]`: no actual reviews and entire testimonials section hidden. Do not invent endorsements. Values, if supplied, are DOM-built using `textContent` before card HTML insertion; optional city appended. Markdown lists testimonials headings even though live HTML hides section.
- `ORDERS=[]`: toast stays invisible. With real orders it starts after `3000ms`, cycles array every `9000ms`, shows each for `4500ms`; message `[nama] dari [kota] baru membeli [item]` and optional ` · [menit] menit lalu`. Toast uses `role="status" aria-live="polite"`, pointer events disabled. `menit` is static provided data, not elapsed time recalculation. Do not fabricate sales activity.
- `DEADLINE=""`: promo countdown strip stays hidden. Given real parseable future date, JS shows `HH:MM:SS`, updates each second, and hides on expiry. Hours represent total remaining hours (not modulo 24). Invalid date yields `NaN:NaN:NaN` because source lacks validation. Visible package and hero promo pricing **does not change on expiry**; countdown only affects strip visibility. Markdown exports strip text without its conditional state or timer value. Do not show perpetual/false urgency.
- Copy/pricing consistency: `4 × Rp29.000 = Rp116.000`, minus `Rp60.000` equals `Rp56.000`; `6 × Rp29.000 = Rp174.000`, minus `Rp109.000` equals `Rp65.000`. DWC.AI explicitly promised for six-book package and hero/bonus marketing; source does **not** explicitly grant it to one-book or four-book buyers despite generic fifth buying step/proof. Preserve distinction or resolve with owner.
- Markdown lacks JS-generated six descriptions, live cover assets, checkout buttons and state semantics. HTML remains authority for rendered content and actions. The Markdown logo `DWC**.BOOKS**` and touching nav links reflect extraction formatting, not literal UI typography/spacing.
